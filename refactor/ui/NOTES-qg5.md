## 二、状态机

### 1. 分区内容四态（m9520c:3172-3234，判定顺序即优先级）

```

videos 空 && error != null           → ERROR   （"该分区加载失败" + 重试按钮，qg5:3183）
videos 空 && error == null           → EMPTY   （"该分区暂无内容"，无按钮，qg5:3189）
videos 非空                          → CONTENT （c21.m1907e 视频网格 + 分页，qg5:3191-3229）
```

## 六、存疑清单

1. **空态页按钮↔回调映射**（m9524e + p30/o30 + C0385ao）：按反编译字面，"重试"→`hu2.m5240v(ab4.f316Q)`（C0385ao case1）、"设置"→`hu2.f8502m.m4015r(false)`（C0385ao case2）、"前往设置"→`m4015r(false)`。语义上像是 lambda 构造参数序被 jadx 置换（重试应调 m4015r、设置应打开设置页）。两个候选映射都已在 NOTES 记录，待 Android 侧联调确认。
2. **s30 自动推进的"边缘"判定**（m9516a:1831-1833）：`z5 = (lastGroup.videos.isEmpty() ^ true) == true ? true : false` 反编译失真，无法确认是"到达最后一个非空分组"还是"当前项为末项"。规格按布尔参数透传（shouldAutoAdvance）。
3. **底部按钮文案**（m9524e:3421）：内容 lambda `uc0(3)` 仅执行 `j16.f10616v.invoke(...)`（全局"打开配置面板"动作），按钮文本在该 lambda 内无字面量；`uc0 case0`（"配置管理"+SwitchAccount 图标）是同类最接近候选。文案待确认。
4. ~~**m9518b 按键处理器 `C0412be`**~~ → **已结案（smali 补读，apktool baksmali）**：
   `C0412be`（dex 原名 `be`，classes2.dex，留档 `.workbuddy/C0412be.smali.txt`）实为
   **R8 合并 lambda 分发类**——单 `invoke` 方法内 `packed-switch 0x0..0x1c` 共 29 个
   case，每个 case 是不同 lambda 的逻辑（LiveRoom.getResolvedRoomIdx、
   vq3.setPositionProvider、各种 StateListenable 写回……），**0 处 KeyEvent/KEYCODE**。
   它不是按键处理器，qg5 的按键语义与其他页面一致走 Compose 焦点系统（见 NOTES-on5
   §6-1 与 COVERAGE 播放器 UI 行的结案结论）。jadx "1396 指令单元溢出" 的方法即此
   invoke（2870 行 smali）。**无行为丢失**。
