# AxTV

面向 Android TV 与电视盒子的抖音客户端。为遥控器操作设计：方向键移动焦点、确定键进入、返回键逐级退出，界面使用 Compose for TV 构建。

> 当前版本 0.1.8，仍在开发中。下列功能、页面与小组件均按当前实现状态描述。
>
> 本仓库只发布安装包与更新日志，源码不公开。

## 功能

### 已接入主界面

- **首页推荐信息流**：真实接口数据，展示作者、文案、点赞 / 评论 / 收藏计数；支持焦点移动、焦点记忆，焦点或滚动接近列表末尾时自动续页（电视没有上滑手势，不再需要手动点「加载更多」）。每条卡片右侧带就近的「详情」按钮，确认键仍是直接播放。公开接口带上设备级匿名身份即可取数，未登录也能看到内容。
- **精选频道**：分区 Tab（来自频道设置接口），分区内视频网格、滚动到底自动续页、分区状态机（加载 / 失败重试 / 空态），点击条目进入播放并支持队列内切换；卡片同样带「详情」入口。
- **哔哩（B 站）**：顶栏一级入口，独立视频源，与抖音共用播放、详情与弹幕外壳。首页四个标签——推荐 / 热门 / 排行 / 分区（常用分区可选），推荐与热门滚到列表末尾自动续页，「换一批」让热门按页轮换、分区在已取到的全量里本地切片；未登录即可浏览与播放，接口失败显示错误与重试，不伪装成空列表。
- **哔哩播放与画质**：匿名走 MP4 720P / 360P，登录后走 DASH 1080P，档位按本机 MediaCodec 实际解码能力过滤。清晰度菜单只列真正拿到的轨道，1080P60 / 1080P+ / 4K / HDR 等需要大会员或本机解不了的档位不显示为可选。取流直链约 2 小时过期，播放失败重试会重新取流。播放页以进入时那份列表为播放队列，遥控器上 / 下切条，当前及相邻条目的取流信息提前预取（列表未缓存时退回单条）；弹幕走同一渲染层，支持 gzip / deflate / zlib。
- **哔哩登录**：passport 扫码登录，二维码由本机渲染，不需要 WebView；登录态保存在独立的 `bili_auth`，与抖音 Cookie 互不影响，退出登录只清哔哩哔哩一侧。
- **登录**：扫码登录由电视端登录页内的 SDK 驱动——应用自动点开登录弹窗并展示**页面自己的二维码**（不再自己造码，避免手机确认的会话和页面轮询的不是同一个）；需要网页端二次验证时可直接在浮出的页面上完成。注意：轮询接口要求网页 SDK 生成的 msToken 等反爬令牌，裸 HTTP/自建会话会被风控判 4031，所以本机 WebView 不可用或内核过旧时无法完成扫码登录，请改用手机面板推送登录态或「导入 Cookie」。登录页会显示一行诊断（内核 / 登录弹窗 / 二维码 / 轮询状态），便于反馈问题。另有登录态校验与登出。
- **播放**：基于 Media3 / ExoPlayer 的点播播放；同一播放实例内切换画质、倍速、播完行为（自动下一个 / 暂停 / 重播）、SurfaceView / TextureView 渲染切换、失败后切换备用地址重试、进度显示与跳转。播放队列按窗口推进：起播只带起点附近少量条目，随播放自动追加并继续翻页，不会一次性预加载整份列表。播放浮层两套按键语义：焦点在画面层时上 / 下换条、左 / 右 ±10s 微调、确认播放暂停；**长按下键**把焦点交给下方控制栏，此后方向键走焦点导航、确认键激活「播放菜单 / 弹幕 / 合集」，BACK 一次把焦点交回画面层。控制栏另有「详情」入口，从首页 / 精选 / 搜索 / 作者 / 合集 / 单作品六条播放入口都能跳到当前条目的详情页（返回即回到播放页接着播），条目没有作品 id 时该入口不出现；播放页顶部信息条显示当前条目的发布时间，接口没给时间的条目不显示这一项。哔哩的播放数据不含发布时间，哔哩播放页因此不显示这一项。
- **设置**：按「显示与外观 / 播放与画质 / 弹幕 / 直播 / 账号与登录 / 接口身份 / 关于」分组、两栏排列；应用共 83 个配置键（含电视台八个），除需要系统 TV Provider 授权、侧载拿不到的「TV 桌面频道」外都有实际消费点：电视台的源列表 / 禁用内置源 / 分组覆盖 / 隐藏死链 / 收藏 / 最近观看 / 源加载超时在「电视台」列表与播放页消费（不在设置列表里显示），`iptv_last_channel` 目前只在切台时写入、还没有读取方，用于「回到上次看的台」的入口接入后才会生效；其余配置改完立即生效（无需重启）。含「客户端身份分支」（Web 接口 / Webcast / App Feed，默认 Web 接口），统一决定请求 User-Agent 与签名输入。
- **检查更新**：从 GitHub Releases 获取版本信息，校验 SHA-256、APK 签名与包名后下载安装；任一校验不可用即中止。发布包按 ABI 拆分，更新时优先下载与本机架构匹配的包，没有匹配包再退回通用包。0.1.4 及更早版本的更新器受签名读取问题影响，需要手动安装一次 0.1.5，之后可正常应用内更新。
- **崩溃日志**：未捕获异常落盘，并提供崩溃信息页面。
- **手机面板**：电视启动后开启 9978（Cookie/互动凭据推送）、9979/9980（搜索输入）服务；手机通过设置页「二维码链接」里的带令牌地址扫码接入，所有请求需 `PanelAuth` 令牌。

### 由入口可达的页面

顶栏：首页 / 精选 / 哔哩 / 搜索 / 直播 / 电视台 / 合集 / 热榜 / 个人 / 设置；详情、搜索结果、直播间、合集详情、播放器等由这些入口进入。

- **视频详情**：作者与简介、点赞 / 收藏 / 不喜欢、评论与楼中楼、加载更多评论；页内小窗播放器、相关推荐卡、评论行、按钮与统计块与哔哩详情共用同一套组件。
- **哔哩详情**：与抖音详情同款布局——封面、UP 主头像、简介（受「详情页显示简介」开关控制）、评论、相关推荐；多 P 视频的分P 芯片与「全屏播放」同排横向滚动，点相关推荐在本页切换到那条详情。
- **哔哩播放页**：以进入播放页时那份列表为队列，遥控器上 / 下切条，当前及相邻条目取流信息提前预取（列表未缓存时退回单条）；清晰度只列实际拿到的轨道，弹幕与抖音走同一渲染层。
- **搜索**：最近搜索、热搜词、联想词，视频 / 用户 / 直播结果；视频结果支持综合 / 最新发布 / 最多点赞排序，列表滚动到底自动续页。
- **热榜**：全站热搜榜（名次 / 热词 / 热度），点一行进入该词的搜索结果。
- **直播**：直播列表与直播间，含在线人数、清晰度选择与直播弹幕。
- **电视台（IPTV）**：内置直播源目录 + 用户自推源，独立于「直播」分区。换台用 ↑↓（只在当前分组内循环）、数字键 0-9 直达组内频道号、确认键打开换台浮层（最近 / 收藏 / 分组）、MENU 收藏；播放页 MENU 打开节目单（正在播 / 接下来，当前节目高亮）。列表页有频道搜索（不输入时直接浏览全部可见频道）与「源管理」（内置源启用 / 禁用、我的源两次确认删除），频道卡片按 MENU 手动改分组 / 新建分组 / 恢复默认，已拉过清单时都是离线重合并。活性三态（未探测 / 可用 / 已死亡，连续 3 次失败判死）+ 目录 7 天 / 活性 24 小时双有效期，只有全部候选确证死亡才隐藏频道；源健康与频道活性分开显示。
- **合集与追更**：合集详情、剧集列表、上次播放定位、收藏合集、我的系列；列表与剧集都是滚到接近末尾自动续页，条目右侧可就近进详情。
- **个人中心**：历史、收藏、稍后再看；历史与稍后再看的行尾带「详情」入口；未登录时明确提示「去登录」，不显示空白页。

### 桌面小组件（6 个）

- **继续观看 / 稍后再看 / 合集追更 / 关注的直播 / 搜索热词**：真实接口数据，封面下载到本地缓存（按封面 URL 缓存，失败回落纯色占位）。
- **正在播放**：显示当前进程内的播放内容；播放会话未建立时媒体键无效。
- 点击组件可进入应用对应页面。

### TV 适配

- 遥控器 / 键盘焦点导航，返回键语义与页面焦点恢复；媒体键（上一首 / 下一首 / 播放暂停 / 快退 / 快进）按原版映射为方向键与确认键，只有媒体键的老遥控器也能操作。
- TV 桌面启动入口。
- 桌面小组件后台定时刷新（WorkManager）。

## 安装

- 系统要求：Android 8.0（API 26）及以上，适用于 Android TV 与电视盒子。
- 从 Releases 下载 APK 后执行 `adb install -r AxTV.apk`，或在电视文件管理器中安装（需允许安装未知来源应用）。
  通用包为 `AxTV-<版本>-all.apk`（含全部 ABI，资源名排序最靠前）；`AxTV-<版本>-arm64-v8a.apk` / `-armeabi-v7a` / `-x86` / `-x86_64` 是按 ABI 拆分的精简包，按设备架构选装即可。
- 首次使用建议先在设置中完成登录：扫码或导入 Cookie。

## 构建与发布

本仓库只发布安装包与更新日志，源码不公开。发布包在本地源码目录构建后手工上传：

```bash
cd android
./gradlew :app:assembleRelease -PsplitAbi=true
# 产物在 app/build/outputs/apk/release/：
#   app-universal-release.apk（通用包，含全部 ABI）
#   app-arm64-v8a-release.apk / app-armeabi-v7a-release.apk / app-x86-release.apk / app-x86_64-release.apk
```

上传前按 `AxTV-<版本>-all.apk` 与 `AxTV-<版本>-<abi>.apk` 改名，先传通用包再传 ABI 包。
`-all` 在资源名排序里最靠前，旧客户端按顺序取第一个 apk 时也会拿到通用包。
release 构建请放在本地磁盘副本里跑，网络盘上 aapt2 会超时。

## 已知限制

- 首页、精选、直播等公开接口未登录可用；搜索（服务端返回 2483）与个人中心（历史 / 收藏 / 稍后再看）要求账号态，未登录时提示去登录。
- 扫码登录依赖手机端抖音确认，二维码过期需刷新；登录态通过 Cookie 持久化。系统 WebView 过旧导致登录页不可用时，可改用手机推送登录信息 / 导入 Cookie。
- 弹幕渲染层已接入播放浮层；未提供静态弹幕时默认把点播**一级评论**转成弹幕（评论列表是公开接口，未登录也会取；无评论或请求失败时为空，可用 `adb logcat -s AxTV_DANMAKU` 查看取数结果）。
- 「正在播放」小组件只反映本进程状态，进程结束后清空。
- 手机面板要求电视与手机在同一局域网，并使用电视设置页展示的带令牌地址接入（令牌每次启动重新生成）。
- 更新包必须带 SHA-256 digest，且签名与包名要与本机一致；任一校验不可用都会中止安装。
- 登出会清空本机保存的全部账号凭据（多账号需重新登录）。
- 哔哩：搜索接口核心层已实现，但电视端输入通路未接，入口暂未开放。匿名可播 MP4 720P / 360P，1080P 需要登录；大会员档位（1080P60 / 1080P+ / 4K / HDR / 杜比）未做验证，一律不显示为可选项。评论匿名只返回首屏几条，登录后才能分页。多段 MP4（`durl` 分段）未做串接；点赞 / 投币 / 收藏 / UP 主主页 / 历史 / 合集未实现。
- 哔哩与抖音的登录态互相独立：哔哩「退出登录」只清 `bili_auth`；抖音的登出仍会清空本机全部抖音凭据（多账号需重新登录）。
- 电视台：首次进入需要联网拉一次清单，拉成功后才能完全离线启动。分组内的频道号是组内序号，目录重拉后可能变化。节目单按频道显示名匹配（未持久化 tvg-id），未匹配的频道显示「暂无节目单」。
- 尚未完成全量真机回归，部分接口行为可能随服务端策略变化。
