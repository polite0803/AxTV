# AxTV

面向 Android TV 与电视盒子的抖音客户端。为遥控器操作设计：方向键移动焦点、确定键进入、返回键逐级退出，界面使用 Compose for TV 构建。

> 当前版本 0.0.3，仍在开发中。下面按「已接入主界面」「已实现、待接入」「桌面小组件」「系统能力」区分实际状态。

## 功能

### 已接入主界面

- **首页推荐信息流**：真实接口数据，展示作者、文案、点赞 / 评论 / 收藏计数；支持焦点移动、焦点记忆，焦点或滚动接近列表末尾时自动续页（电视没有上滑手势，不再需要手动点「加载更多」）。公开接口带上设备级匿名身份即可取数，未登录也能看到内容。
- **精选频道**：分区 Tab（来自频道设置接口），分区内视频网格、分页加载、分区状态机（加载 / 失败重试 / 空态），点击条目进入播放并支持队列内切换。
- **登录**：扫码登录（二维码渲染、状态轮询、刷新与过期重试）、手动导入 Cookie、登录态校验与登出。账号被风控要求二次验证时：短信验证码走应用侧数字键盘（自动写回登录页并提交），滑块 / 刷脸这类无法代填的会把登录页浮出来操作。
- **播放**：基于 Media3 / ExoPlayer 的点播播放；同一播放实例内切换画质、倍速、播完行为（自动下一个 / 暂停 / 重播）、SurfaceView / TextureView 渲染切换、失败后切换备用地址重试、进度显示与跳转。播放浮层两套按键语义：焦点在画面层时上 / 下换条、左 / 右 ±10s 微调、确认播放暂停；**长按下键**把焦点交给下方控制栏，此后方向键走焦点导航、确认键激活「播放菜单 / 弹幕 / 合集」，BACK 一次把焦点交回画面层。
- **设置**：69 个生效配置键，覆盖播放、弹幕、直播、外观、账号、接口身份等分组；含「客户端身份分支」（Web 接口 / Webcast / App Feed，默认 Web 接口），统一决定请求 User-Agent 与签名输入。
- **检查更新**：从 GitHub Releases 获取版本信息，校验 SHA-256、APK 签名与包名后下载安装；任一校验不可用即中止。
- **崩溃日志**：未捕获异常落盘，并提供崩溃信息页面。
- **手机面板**：电视启动后开启 9978（Cookie/互动凭据推送）、9979/9980（搜索输入）服务；手机通过设置页「二维码链接」里的带令牌地址扫码接入，所有请求需 `PanelAuth` 令牌。

### 由入口可达的页面

顶栏：首页 / 精选 / 搜索 / 直播 / 合集 / 个人 / 设置；详情、搜索结果、直播间、合集详情、播放器等由这些入口进入。

- **视频详情**：作者与简介、点赞 / 收藏 / 不喜欢、评论与楼中楼、加载更多评论。
- **搜索**：最近搜索、热搜词、联想词，综合 / 视频 / 直播 / 用户结果。
- **直播**：直播列表与直播间，含在线人数、清晰度选择与直播弹幕。
- **合集与追更**：合集详情、剧集列表、上次播放定位、收藏合集、我的系列；列表与剧集都是滚到接近末尾自动续页。
- **个人中心**：历史、收藏、稍后再看；未登录时明确提示「去登录」，不显示空白页。

### 桌面小组件（6 个）

- **继续观看 / 稍后再看 / 合集追更 / 关注的直播 / 搜索热词**：真实接口数据，封面下载到本地缓存（按封面 URL 缓存，失败回落纯色占位）。
- **正在播放**：显示当前进程内的播放内容；播放会话未建立时媒体键无效。
- 点击组件可进入应用对应页面。

### TV 适配

- 遥控器 / 键盘焦点导航，返回键语义与页面焦点恢复；媒体键（上一首 / 下一首 / 播放暂停 / 快退 / 快进）按原版映射为方向键与确认键，只有媒体键的老遥控器也能操作。
- TV 桌面启动入口。
- 桌面小组件后台定时刷新（WorkManager）。

## 安装

- 系统要求：Android 8.0（API 26）及以上，适用于 Android TV 与电视盒子。
- 从 Releases 下载 APK 后执行 `adb install -r AxTV.apk`，或在电视文件管理器中安装（需允许安装未知来源应用）。
- 首次使用建议先在设置中完成登录：扫码或导入 Cookie。

## 构建

环境：JDK 17、Android SDK（compileSdk 等参数见工程配置）。

```bash
cd android
./gradlew :app:assembleDebug
# Windows
gradlew.bat :app:assembleDebug
```

产物位于 `android/app/build/outputs/apk/debug/app-debug.apk`。仓库已包含构建所需的全部源码。

## 已知限制

- 首页、精选、搜索、直播等公开接口未登录可用；个人中心（历史 / 收藏 / 稍后再看）要求账号态，未登录时提示去登录。
- 扫码登录依赖手机端抖音确认，二维码过期需刷新；登录态通过 Cookie 持久化。
- 弹幕渲染层已接入播放浮层；未提供静态弹幕时默认把点播评论转成弹幕，评论拉取失败时静默为空。
- 「正在播放」小组件只反映本进程状态，进程结束后清空。
- 手机面板要求电视与手机在同一局域网，并使用电视设置页展示的带令牌地址接入（令牌每次启动重新生成）。
- 更新包必须带 SHA-256 digest，且签名与包名要与本机一致；任一校验不可用都会中止安装。
- 登出会清空本机保存的全部账号凭据（多账号需重新登录）。
- 尚未完成全量真机回归，部分接口行为可能随服务端策略变化。
