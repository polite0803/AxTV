# AxTV

面向 Android TV 与电视盒子的抖音客户端。为遥控器操作设计：方向键移动焦点、确定键进入、返回键逐级退出，界面使用 Compose for TV 构建。

> 当前版本 0.1.5，仍在开发中。下列功能、页面与小组件均按当前实现状态描述。
>
> 本仓库只发布安装包与更新日志，源码不公开。

## 功能

### 已接入主界面

- **首页推荐信息流**：真实接口数据，展示作者、文案、点赞 / 评论 / 收藏计数；支持焦点移动、焦点记忆，焦点或滚动接近列表末尾时自动续页（电视没有上滑手势，不再需要手动点「加载更多」）。每条卡片右侧带就近的「详情」按钮，确认键仍是直接播放。公开接口带上设备级匿名身份即可取数，未登录也能看到内容。
- **精选频道**：分区 Tab（来自频道设置接口），分区内视频网格、分页加载、分区状态机（加载 / 失败重试 / 空态），点击条目进入播放并支持队列内切换；卡片同样带「详情」入口。
- **登录**：扫码登录由电视端登录页内的 SDK 驱动——应用自动点开登录弹窗并展示**页面自己的二维码**（不再自己造码，避免手机确认的会话和页面轮询的不是同一个）；需要网页端二次验证时可直接在浮出的页面上完成。注意：轮询接口要求网页 SDK 生成的 msToken 等反爬令牌，裸 HTTP/自建会话会被风控判 4031，所以本机 WebView 不可用或内核过旧时无法完成扫码登录，请改用手机面板推送登录态或「导入 Cookie」。登录页会显示一行诊断（内核 / 登录弹窗 / 二维码 / 轮询状态），便于反馈问题。另有登录态校验与登出。
- **播放**：基于 Media3 / ExoPlayer 的点播播放；同一播放实例内切换画质、倍速、播完行为（自动下一个 / 暂停 / 重播）、SurfaceView / TextureView 渲染切换、失败后切换备用地址重试、进度显示与跳转。播放浮层两套按键语义：焦点在画面层时上 / 下换条、左 / 右 ±10s 微调、确认播放暂停；**长按下键**把焦点交给下方控制栏，此后方向键走焦点导航、确认键激活「播放菜单 / 弹幕 / 合集」，BACK 一次把焦点交回画面层。
- **设置**：按「显示与外观 / 播放与画质 / 弹幕 / 直播 / 账号与登录 / 接口身份 / 关于」分组、两栏排列；应用共 81 个配置键，除需要系统 TV Provider 授权、侧载拿不到的「TV 桌面频道」外都有实际消费点（电视台的分组覆盖与隐藏死链在「电视台」页消费），改完立即生效（无需重启）。含「客户端身份分支」（Web 接口 / Webcast / App Feed，默认 Web 接口），统一决定请求 User-Agent 与签名输入。
- **检查更新**：从 GitHub Releases 获取版本信息，校验 SHA-256、APK 签名与包名后下载安装；任一校验不可用即中止。发布包按 ABI 拆分，更新时优先下载与本机架构匹配的包，没有匹配包再退回通用包。0.1.4 及更早版本的更新器受签名读取问题影响，需要手动安装一次 0.1.5，之后可正常应用内更新。
- **崩溃日志**：未捕获异常落盘，并提供崩溃信息页面。
- **手机面板**：电视启动后开启 9978（Cookie/互动凭据推送）、9979/9980（搜索输入）服务；手机通过设置页「二维码链接」里的带令牌地址扫码接入，所有请求需 `PanelAuth` 令牌。

### 由入口可达的页面

顶栏：首页 / 精选 / 搜索 / 直播 / 电视台 / 合集 / 热榜 / 个人 / 设置；详情、搜索结果、直播间、合集详情、播放器等由这些入口进入。

- **视频详情**：作者与简介、点赞 / 收藏 / 不喜欢、评论与楼中楼、加载更多评论。
- **搜索**：最近搜索、热搜词、联想词，综合 / 视频 / 直播 / 用户结果。
- **热榜**：全站热搜榜（名次 / 热词 / 热度），点一行进入该词的搜索结果。
- **直播**：直播列表与直播间，含在线人数、清晰度选择与直播弹幕。
- **电视台（IPTV）**：内置直播源目录，支持分组覆盖、存活探测与隐藏死链、画质 / 刷新策略，独立于「直播」分区。
- **合集与追更**：合集详情、剧集列表、上次播放定位、收藏合集、我的系列；列表与剧集都是滚到接近末尾自动续页，条目右侧可就近进详情。
- **个人中心**：历史、收藏、稍后再看；历史与稍后再看的行尾带「详情」入口；未登录时明确提示「去登录」，不显示空白页。

### 桌面小组件（6 个）

- **继续观看 / 稍后再看 / 合集追更 / 关注的直播 / 搜索热词**：真实接口数据，封面下载到本地缓存（按封面 URL 缓存，失败回落纯色占位）。
- **正在播放**：显示当前进程内的播放内容；播放会话未建立时媒体键无效。
- 点击组件可进入应用对应页面。

### TV 适配

- 遥控器 / 键盘焦点导航，返回键语义与页面焦点恢复；媒体键（上一首 / 下一首 / 播放暂停 / 快退 / 快进）按原版映射为方向键与确认键，只有媒体键的老遥控器也能操作。
- TV 桌面启动入口。
- 桌面小组件后台定时刷新（WorkManager）。

## 安装

- 系统要求：Android 8.0（API 26）及以上，适用于 Android TV 与电视盒子。
- 从 Releases 下载 APK 后执行 `adb install -r AxTV.apk`，或在电视文件管理器中安装（需允许安装未知来源应用）。
  通用包为 `AxTV-<版本>-all.apk`（含全部 ABI，资源名排序最靠前）；`AxTV-<版本>-arm64-v8a.apk` / `-armeabi-v7a` / `-x86` / `-x86_64` 是按 ABI 拆分的精简包，按设备架构选装即可。
- 首次使用建议先在设置中完成登录：扫码或导入 Cookie。

## 构建与发布

本仓库只发布安装包与更新日志，源码不公开。发布包在本地源码目录构建后手工上传：

```bash
cd android
./gradlew :app:assembleRelease -PsplitAbi=true
# 产物在 app/build/outputs/apk/release/：
#   app-universal-release.apk（通用包，含全部 ABI）
#   app-arm64-v8a-release.apk / app-armeabi-v7a-release.apk / app-x86-release.apk / app-x86_64-release.apk
```

上传前按 `AxTV-<版本>-all.apk` 与 `AxTV-<版本>-<abi>.apk` 改名，先传通用包再传 ABI 包。
`-all` 在资源名排序里最靠前，旧客户端按顺序取第一个 apk 时也会拿到通用包。
release 构建请放在本地磁盘副本里跑，网络盘上 aapt2 会超时。

## 已知限制

- 首页、精选、直播等公开接口未登录可用；搜索（服务端返回 2483）与个人中心（历史 / 收藏 / 稍后再看）要求账号态，未登录时提示去登录。
- 扫码登录依赖手机端抖音确认，二维码过期需刷新；登录态通过 Cookie 持久化。系统 WebView 过旧导致登录页不可用时，可改用手机推送登录信息 / 导入 Cookie。
- 弹幕渲染层已接入播放浮层；未提供静态弹幕时默认把点播**一级评论**转成弹幕（评论列表是公开接口，未登录也会取；无评论或请求失败时为空，可用 `adb logcat -s AxTV_DANMAKU` 查看取数结果）。
- 「正在播放」小组件只反映本进程状态，进程结束后清空。
- 手机面板要求电视与手机在同一局域网，并使用电视设置页展示的带令牌地址接入（令牌每次启动重新生成）。
- 更新包必须带 SHA-256 digest，且签名与包名要与本机一致；任一校验不可用都会中止安装。
- 登出会清空本机保存的全部账号凭据（多账号需重新登录）。
- 尚未完成全量真机回归，部分接口行为可能随服务端策略变化。
