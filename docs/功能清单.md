## 9. 手机 ↔ 电视 局域网面板

电视端起 HTTP 服务，手机浏览器打开即可操作（页面在 `assets/web/`）：

| 页面/路径 | 功能 |
|---|---|
| `submit.html` | 推送登录信息：粘贴 Cookie → 推送到电视；提取互动凭据脚本；手动填 security / private_key；导出 logcat |
| `search.html` | 远程输入搜索词，电视立即跳转搜索 |
| `panel-head.html` | 公共页头/主题（`THEME_CSS`、`PANEL_HEAD`、`DEVICE_NAME` 占位符由服务端替换） |
| 地址选择 | 优先 Wi-Fi / 以太网地址，避免 Wi-Fi Direct 的 `p2p0`（2.3.42 修复） |
| 常驻 | Cookie 推送服务随应用启动常驻（2.3.43 变更） |
