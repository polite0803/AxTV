## UI 层重构的注意事项

1. **Compose 编译产物不可直接翻译**。Kotlin 的 `@Composable` 在反编译结果里变成
   带 `Composer`/`int` 参数的方法 + 大量 `Composer.startRestartGroup` 之类的样板，
   且 R8 把 `androidx.compose.runtime` 的部分符号也改名了。
   **正确做法**：按「这个页面显示什么、点了做什么」重建，而不是逐行翻译。
   行为依据 = 中文字面量（文案）+ 引用的 model 字段 + 调用的 `n11` 方法。
2. **遥控器交互是真需求**。App 是 TV 应用，`lq2` 里「左右键微调，长按加速」「双击返回退出」
   这类逻辑必须保留，这是和手机版最不同的地方。
3. **主题令牌**在 `p000` 里有大量 `*Fg`/`*Bg` 字符串（如 `searchResultsFilterFg`、
   `userCardBg`），说明配色是 token 化的，重建时建议建一套同样的 token 表。
4. **国际化**：`res/values-zh-rCN|zh-rHK|zh-rTW` 存在，但应用自身文案基本硬编码在 Compose 里
   （`res/values/strings.xml` 只有库字符串）。重建时建议统一走 `strings.xml`。
