# 核心流程（链路图）

每条链路都给出「入口 → 关键类 → 出口」和可回溯的原类。细节见对应模块的 `NOTES.md`。

---

## 1. 启动

```
Application.onCreate()                                  [com/github/mytv/dv/MyApplication.java]
 ├─ WidgetRefreshScheduler.scheduleAll(context)         小组件定时刷新（WorkManager）
 ├─ VideoPlayUrlResolver.init(context)                  取流解析器需要 context（读设备信息）
 ├─ registerActivityLifecycleCallbacks(...)             前后台/页面栈埋点
 ├─ QuickJSLoader.init()                                加载 libquickjs-android-wrapper.so
 │    └─ 失败只 WARN("QuickJSLoader.init() failed (QuickJS not available?)")，不阻断启动
 ├─ async: C1285k(13) → Cookie 推送服务常驻启动           [p000/C1285k.java]
 ├─ Thread.setDefaultUncaughtExceptionHandler(...)      崩溃兜底 → CrashActivity
 └─ Log.i("myDV", "Application onCreate 完成")
```

崩溃兜底拼装的内容（原样）：时间 / 设备（`Build.BRAND + MODEL`）/ 应用版本 `2.3.43 (43)` /
`Android RELEASE (API SDK)` / 线程名 / 异常类与 message / 根因 / 完整堆栈，然后启动
`CrashActivity`（`crash_info` extra），`sleep(500)` 后 `Process.killProcess`。

## 2. 一次抖音 API 请求（含签名）

```
业务层（on5 / eu5 / ye4 / qg5 …）
 └─ n11.method(...)                       [p000/n11.java，5659 行，全部接口]
      ├─ 组装公共参数（device_platform / aid / version_code / msToken / ttwid / …）
      ├─ 需要签名时：C1608s.m10095c(query, data, uri, userAgent)     ← 见 §3
      │    └─ 返回 a_bogus 后 map.put("a_bogus", value)             [n11.java:963 / :1041]
      ├─ 用户中心签名链：map.put("uifid") / map.put("timestamp")
      │    + map.put("x-secsdk-web-signature", m7999i(map, uifid, timestamp))
      │    └─ UIFID / UIFID_TEMP 都缺失时只打 WARN「将不带 x-secsdk-web-signature」
      └─ OkHttp 发送 → kotlinx.serialization 解析 → model/*
```

## 3. 签名（a_bogus / 直播 sign）

两条**互不相通**的 QuickJS 运行时：

| 运行时 | 线程名 | 加载脚本 | 用途 | 超时 |
|---|---|---|---|---|
| `quickjs-abogus` | `quickjs-abogus` | browser shim → `abogus_dy.js` → `initABogus()` → `sign.js` | a_bogus、`__ac_signature` | 初始化 30s |
| `quickjs-sign` | `quickjs-sign` | `sign.js`（裸跑，不注入 shim） | 直播 `getMSSDKSignature` | 初始化 15s |

```
sign():      ensureReady() → 拼脚本（escapeFull 转义）→ evaluate
             → 解析 {"ok":true,"value":…} → 失败一律返回 ""（各分支日志不同）
signLive():  MD5(固定参数串含 room_id / user_unique_id) → getMSSDKSignature(msStub, UA)
             → 结果含 '-' 或 '=' 就原地重试（无上限、无退避）
```

> 完整时序、常量表、11 条「实现风险」（含超时常量单位误用、销毁后野指针、live 重试死循环）
> 见 `refactor/sign/NOTES.md`。

## 4. 取流与播放

```
合集/详情拿到 Aweme → VideoPlayUrlResolver 选流
 ├─ 多码率 BitRate 择优（分辨率 / 码率 / 容器 / 是否 HLS）
 ├─ 生成 MediaItem
 └─ VideoPlayer (ro5) : ExoPlayer + 三种渲染（SurfaceView / TextureView / GLSurfaceView）
      ├─ 首帧前静音 → 首帧后恢复
      ├─ 解码失败 → ko5 自动降 H.264 档位重载（"视频解码失败，已切换到 H.264 档位重载"）
      ├─ 加载超时 video_load_timeout_seconds → 提示 + 重试
      ├─ 缩放：适应 / 填充 / 16:9 / 原始（竖屏与横屏不同策略）
      ├─ 连播：auto_next / auto_play_next_video / playback_completion_action
      ├─ 缓存：VideoMediaCache（边播边缓存 + 清理）
      └─ PIP：PipActionReceiver 处理 PIP_PLAY / PIP_PAUSE / PIP_NEXT
```

## 5. 直播

```
直播间列表（/webcast/feed/ 等）→ 进房（/webcast/room/web/enter/）
 ├─ LiveCoreSdkData → LiveStreamQuality 选流（live_video_resolution 偏好）
 └─ LiveWS：WebSocket + protobuf 帧
      ├─ 握手帧（protobuf 手写编码）→ 心跳保活 → 断线重连
      ├─ 弹幕帧 → Danmaku 解析 → 弹幕渲染（速度按窗口宽度，横竖屏一致）
      └─ 直播签名走 quickjs-sign（见 §3）
```

## 6. 手机 ↔ 电视面板

```
电视端启动时：9978 Cookie 推送服务常驻
设置开关打开：9979 搜索输入页面 + 9980 搜索输入 WebSocket

手机浏览器 → http://<电视局域网IP>:9978/submit
 ├─ GET  /submit     → submit.html（替换 {{DEVICE_NAME}} / {{THEME_CSS}} / {{PANEL_HEAD}}）
 ├─ GET  /api/info   → {"success":true,"device_name":…,"app_name":"myDV"}
 ├─ POST /api/submit → {cookie, security_payload, private_key} → 写入 douyin_auth
 └─ GET  /logcat     → logcat -t 10000 -v threadtime 下载

搜索：手机 9979 页面 → WS 9980 发 {"type":"input"|"search","text":…} → 电视实时输入/搜索
     电视 → 手机 {"type":"tv_text","text":…}（握手后补发一次，之后广播）
```

> 完整路由表、WebSocket 帧格式、**安全风险（明文 HTTP、零鉴权、CORS 全开、可被局域网内任意网页 CSRF 推送登录态）**
> 见 `refactor/panel/NOTES.md`。

## 8. 想自己追一条链路时的套路

1. `docs/class-index.csv` 里按 `log_tags`、`zh_sample`、`api_paths` 过滤定位候选类
2. 打开 `src/app/p000/<class>.java`，看 `JADX INFO: renamed from:` 注释恢复原始方法名线索
3. 反向找调用方：`grep -rn "n11.f145" src/app/p000/*.java`（字段名虽是混淆的，但全局唯一）
4. 字符串是**最可靠的锚点**：中文文案、API 路径、SharedPreferences 键名、日志 TAG 都不会被混淆
5. 需要确认某个常量/分支时，回到 `src/resources/`（Manifest、assets JS、模板 HTML）
